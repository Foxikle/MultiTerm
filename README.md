# Operations:
- **touch** Create a new file (touch file.txt)
- **cat** Read a file (cat file.txt)
- **rm** delete a file (rm file.txt)
- **>** Write to a file ("Text to write" > file.txt)
- **chtag** Tag a file in some way (chtag file.txt tags, comma separated, nodel)
- **help** Prints out a message like this
